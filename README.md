# Журнал заявок

Настольная программа на Python. В журнале можно просматривать, добавлять и закрывать заявки. У каждой записи есть номер, описание и статус.

## 1. Скачайте проект

**Через браузер.** Откройте репозиторий, нажмите зелёную кнопку **Code**, затем **Download ZIP**. Распакуйте архив и откройте папку `AccountingJournalPy-main`. В ней должны быть файлы `main.py` и `requirements.txt`. [Открыть репозиторий](https://github.com/epbloger/AccountingJournalPy)

**Через Git.** Если Git уже установлен, откройте терминал и выполните команды:

```bash
git clone https://github.com/epbloger/AccountingJournalPy.git
cd AccountingJournalPy
```

## 2. Установите Python

Для проекта используйте **Python 3.12**. На Windows 10/11 (64 бит) скачайте установщик и нажмите **Install Now**. После установки откройте новое окно командной строки. [Скачать установщик для Windows](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe) · [Загрузки для других систем](https://www.python.org/downloads/)

## 3. Установите зависимость и запустите программу

Выполняйте команды из папки, где находится `main.py`. Установка нужна один раз, для следующих запусков достаточно последней команды.

### Windows

Откройте папку с файлом `main.py` в Проводнике. Щёлкните по адресной строке, введите `cmd` и нажмите Enter. В открывшемся окне выполните:

```bat
py -3.12 --version
```

Если в ответе указано `Python 3.12`, выполните следующие команды по одной:

```bat
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если `python main.py` выдаёт `Failed to launch 'C:\Python313\python.exe' (0x80070003)`, Windows пытается запустить Python по отсутствующему пути. Используйте команды выше, которые явно выбирают Python 3.12.

Если после установки Python 3.12 команда `py` недоступна, при стандартной установке для текущего пользователя можно создать окружение напрямую:

```bat
"%LocalAppData%\Programs\Python\Python312\python.exe" -m venv .venv
```

Затем выполните две команды с `.\.venv\Scripts\python.exe` из блока выше.

### macOS и Linux

Откройте терминал и перейдите в папку проекта с помощью `cd`. Затем выполните:

```bash
python3.12 --version
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Если Python 3.12 доступен в терминале только как `python3`, используйте это имя в первых двух командах. На Linux программу запускайте в графическом сеансе.

## 4. Работайте с заявками

- При первом запуске в таблице появятся пять примеров.
- Чтобы добавить заявку, нажмите **Новая заявка**, введите краткое описание проблемы и нажмите **Добавить**.
- Чтобы закрыть открытую заявку, выделите её строку и нажмите **Закрыть заявку**.

Изменения сохраняются автоматически в файле `tickets.json` рядом с `main.py`. Если переносите проект на другой компьютер, скопируйте этот файл в папку новой копии, чтобы сохранить свои заявки.
