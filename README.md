# Журнал заявок

Настольная программа на Python с интерфейсом PySide6.

Установите Python 3.12 и выполните в папке проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

При первом запуске программа создаёт `tickets.json` с пятью примерами. Нажмите «Новая заявка» и введите краткое описание. Чтобы закрыть заявку, выделите её строку и нажмите «Закрыть заявку». Программа автоматически сохраняет изменения в `tickets.json`.
